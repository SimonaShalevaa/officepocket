# OfficePocket

Mobile app for small businesses to track income and expenses, store documents and manage leave requests.

React Native exam project – SoftUni, 2026.

## Tech Stack

- React Native
- Expo

## Installation & Running

```bash
git clone https://github.com/SimonaShalevaa/officepocket.git
cd officepocket
npm install
npx expo start
```

Scan the QR code with the **Expo Go** app on your phone.
